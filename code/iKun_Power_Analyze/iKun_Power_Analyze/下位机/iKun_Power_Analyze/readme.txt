iKun Power Analyze
Author: 混分巨兽龙某某 (CSDN: black_sneak)
Version: V1.0.0
Date: 2026-05-30
License: MIT
iKun Power Analyze is an open-source USB power meter & analyzer based on CH32V203C8T6 and INA226, designed for 
real-time monitoring, logging, and analysis of USB-C/A voltage, current, power, energy, and charging protocols. It features 
a 2.4-inch SPI LCD (240×320, RGB565) and a Qt-based desktop GUI for data visualization, FOTA, and advanced analysis.
